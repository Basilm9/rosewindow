# Rose Window — Acceptance tests (AT-01 to AT-17)

Source: the team's acceptance test plan, reviewed 11/18 by a hand dry run on the reference build. Requirement IDs refer to the SRS, Rev 1.4 (Appendix C lists the same tests). Unless a test says otherwise it starts a fresh run from `localhost:5173/?seed=3` on pattern Novice Rose, in a desktop browser 1280 px wide with the tutorial dismissed. A `?seed=` link always starts a fresh run, and a run started from one never shows the tutorial. Screenshots include the whole browser window so the URL (and therefore the seed) is visible; Playwright runs record the URL in the test log instead. Each test starts from a clean browser profile (no stored game data) unless it says otherwise.
